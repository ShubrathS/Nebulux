    ⓘ About Nebulux

    Nebulux is a multi-agent orchestrator that turns a project description into a complete codebase — plan, design, backend, tests, Docker, README — by coordinating multiple LLMs as a specialist team.

    How it works

    1. Planner reads your description and emits an implementation plan (tech stack, file structure, API contract, design requirements).
    2. The Planner also decides the execution order — backend-first, frontend-first, parallel, or skip stages your project doesn't need.
    3. Designer & Coder run in that order. Each can use any model you pick (Claude, Gemini, Kimi K2.6, Gemma 4, or any custom OpenAI-compatible endpoint).
    4. Supervisor validates every handoff. DevOps writes tests, Docker config, and README at the end.

    Privacy

    Your API keys are stored only in this browser's localStorage and sent with each pipeline request. The server never writes them to disk.
